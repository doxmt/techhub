# PRD: TechHub

## 목표

TechHub는 최신 개발 뉴스, 개발 아티클, 공모전 정보를 한 곳에 모아 보여주는 개발자 허브 커뮤니티다. 사용자는 로그인 없이 최신순 피드에서 관심 주제를 검색/필터링하고, 향후 서비스는 RSS/API 기반 자동 수집으로 신뢰할 수 있는 개발 콘텐츠를 지속적으로 갱신한다.

## 사용자

- 최신 개발 자료를 빠르게 훑고 싶은 개발자
- FE, BE, Cloud, Claude Code, AI Agents 등 관심 주제별 자료를 찾는 학습자
- 개발 뉴스, 글, 공모전 정보를 한 곳에서 확인하려는 커뮤니티 사용자
- 신뢰할 수 있는 RSS/API 소스를 관리하고 피드 품질을 운영하려는 서비스 관리자

## 핵심 기능

1. 공개 콘텐츠 피드
   - 최신 등록순으로 개발 뉴스와 아티클을 보여준다.
   - 첫 화면 상위 탭은 `최신 뉴스`, `아티클`, `공모전`으로 구성한다.
   - UI-first 단계에서 `공모전`은 준비중 상태로 표시하고, 실제 데이터 분류는 후속 DB 확장으로 구현한다.
   - 사용자는 로그인 없이 콘텐츠를 조회할 수 있다.
   - 피드는 무한 스크롤로 더 불러온다.

2. 검색과 필터
   - 제목, 설명, 태그 기반 검색을 제공한다.
   - 섹션(최신 뉴스/아티클/공모전), 주제, 언어, 태그 필터를 제공한다.
   - 검색/필터 상태는 URL query에 유지해 공유와 새로고침 복원이 가능해야 한다.

3. 콘텐츠 상세 페이지
   - `slug + id` 형태의 읽기 쉬운 URL을 사용한다.
   - 제목, 설명, 썸네일, 출처, 섹션, 미디어 타입, 언어, 태그, 등록일을 표시한다.
   - 원문 링크로 이동할 수 있어야 한다.

4. 소스 기반 수집 운영
   - v1 UI 전환 이후 RSS를 지원하는 블로그와 API를 제공하는 서비스 소스를 등록한다.
   - Vercel Cron이 정해진 주기로 RSS/API를 수집하고 중복 콘텐츠를 방지한다.
   - 수집된 콘텐츠는 기본적으로 게시 상태로 저장하되, 추후 소스별 게시 정책을 지원한다.

5. 관리자 대시보드
   - GitHub OAuth로 로그인한다.
   - 허용된 이메일 목록에 포함된 사용자만 관리자 기능을 사용할 수 있다.
   - 관리자는 수집 소스와 콘텐츠 메타데이터를 관리한다.
   - 관리자는 콘텐츠를 게시, 비공개, 수정, 삭제할 수 있다.

## MVP 제외 사항

- AI 요약, AI 태그 추천, AI 추천 피드
- 벡터 검색
- 일반 사용자 콘텐츠 제출
- 사용자 북마크, 좋아요, 조회수 기반 랭킹
- RSS/API 수집 고도화와 소스 관리 UI
- 사용자 제보, 사용자 직접 게시, 모더레이션 워크플로
- 브라우저 확장
- K8s/GitOps 배포
- 댓글, 신고

## 디자인

- Linear처럼 밀도 높고 정돈된 개발자용 도구 UI를 지향한다.
- 화려한 랜딩 페이지보다 최신 커뮤니티 피드와 필터 효율을 우선한다.
- 라이트 테마를 기본으로 제공하고 다크 테마를 지원한다.
- 콘텐츠 카드는 섹션, 썸네일, 제목, 설명, 출처, 태그가 빠르게 스캔되도록 구성한다.

## 성공 기준

- 공개 사용자가 로그인 없이 최신 뉴스/아티클 피드, 검색, 필터, 상세 페이지를 사용할 수 있다.
- 공개 피드는 섹션(최신 뉴스/아티클/공모전), 주제, 언어 필터를 URL query로 유지한다.
- 공모전 탭은 실제 데이터 추가 전까지 준비중 상태를 명확히 표시한다.
- 익명 사용자는 게시된 콘텐츠만 조회할 수 있고 쓰기 작업을 할 수 없다.
- 관리자는 콘텐츠 수정/삭제/게시 상태 변경을 할 수 있다.
- 주요 검증 명령(`lint`, `test`, `build`)이 CI에서 통과한다.
- Vercel Preview와 Production 배포 흐름이 동작한다.

## 미결 사항

- 실제 서비스 도메인
- 관리자 허용 이메일 목록의 초기 값
- Vercel/Supabase 유료 플랜 전환 시점
- RSS/API 수집 대상 초기 소스 목록
- 소스별 자동 게시/검수 정책
- 추후 AI 기능을 도입할 경우 사용할 모델과 비용 정책
