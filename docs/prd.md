# PRD: TechHub

## 목표

TechHub는 개발 관련 아티클과 유튜브 콘텐츠를 관리자가 선별해 등록하고, 사용자가 로그인 없이 최신순 피드에서 검색/필터링할 수 있는 공개 큐레이션 웹앱이다.

## 사용자

- 최신 개발 자료를 빠르게 훑고 싶은 개발자
- FE, BE, Cloud, Claude Code, AI Agents 등 관심 주제별 자료를 찾는 학습자
- 좋은 개발 콘텐츠를 저장하고 공개 피드로 관리하려는 서비스 관리자

## 핵심 기능

1. 공개 콘텐츠 피드
   - 최신 등록순으로 개발 아티클/유튜브 콘텐츠를 보여준다.
   - 사용자는 로그인 없이 콘텐츠를 조회할 수 있다.
   - 피드는 무한 스크롤로 더 불러온다.

2. 검색과 필터
   - 제목, 설명, 태그 기반 검색을 제공한다.
   - 카테고리, 콘텐츠 타입, 언어, 태그 필터를 제공한다.
   - 검색/필터 상태는 URL query에 유지해 공유와 새로고침 복원이 가능해야 한다.

3. 콘텐츠 상세 페이지
   - `slug + id` 형태의 읽기 쉬운 URL을 사용한다.
   - 제목, 설명, 썸네일, 출처, 타입, 언어, 태그, 등록일을 표시한다.
   - 원문 또는 유튜브 링크로 이동할 수 있어야 한다.

4. 관리자 대시보드
   - GitHub OAuth로 로그인한다.
   - 허용된 이메일 목록에 포함된 사용자만 관리자 기능을 사용할 수 있다.
   - 관리자는 URL을 붙여넣어 콘텐츠를 등록한다.
   - 서버가 Open Graph/Twitter/meta 태그를 수집하고, 관리자는 메타데이터를 보정한다.
   - 관리자는 콘텐츠를 게시, 비공개, 수정, 삭제할 수 있다.

## MVP 제외 사항

- AI 요약, AI 태그 추천, AI 추천 피드
- 벡터 검색
- 일반 사용자 콘텐츠 제출
- 사용자 북마크, 좋아요, 조회수 기반 랭킹
- RSS/API 자동 수집
- 브라우저 확장
- K8s/GitOps 배포
- 댓글, 신고, 모더레이션 워크플로

## 디자인

- Linear처럼 밀도 높고 정돈된 개발자용 도구 UI를 지향한다.
- 화려한 랜딩 페이지보다 최신 피드, 필터, 관리자 작업 효율을 우선한다.
- 라이트 테마를 기본으로 제공하고 다크 테마를 지원한다.
- 콘텐츠 카드는 썸네일, 제목, 설명, 출처, 태그가 빠르게 스캔되도록 구성한다.

## 성공 기준

- 관리자가 GitHub OAuth로 로그인하고 URL 기반 콘텐츠를 등록할 수 있다.
- 공개 사용자가 로그인 없이 최신 피드, 검색, 필터, 상세 페이지를 사용할 수 있다.
- 익명 사용자는 게시된 콘텐츠만 조회할 수 있고 쓰기 작업을 할 수 없다.
- 관리자는 콘텐츠 생성/수정/삭제/게시 상태 변경을 할 수 있다.
- 주요 검증 명령(`lint`, `test`, `build`)이 CI에서 통과한다.
- Vercel Preview와 Production 배포 흐름이 동작한다.

## 미결 사항

- 실제 서비스 도메인
- 관리자 허용 이메일 목록의 초기 값
- Vercel/Supabase 유료 플랜 전환 시점
- 추후 AI 기능을 도입할 경우 사용할 모델과 비용 정책
